# Les Amis des Messina — MVP site vitrine

Maquette HTML statique prête pour GitHub + Vercel.

## Contenu

- `index.html` : page vitrine complète
- `vercel.json` : configuration minimale Vercel

## Déploiement rapide

1. Créer un dépôt GitHub.
2. Envoyer `index.html` et `vercel.json` à la racine du dépôt.
3. Aller sur Vercel > Add New Project > Import Git Repository.
4. Sélectionner le dépôt.
5. Laisser les réglages par défaut :
   - Framework Preset : Other
   - Build Command : vide
   - Output Directory : vide ou `.`
6. Cliquer sur Deploy.

## Remarques

Les images actuelles sont des visuels de maquette externes.
Pour une version client finale, remplacer les URLs Unsplash dans `index.html`
par les vraies photos du restaurant, du chef, des plats et des espaces.
